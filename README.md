# HR Data Analysis Dashboard (Excel)
## Project Overview
This project presents an interactive HR Analytics Dashboard built using Microsoft Excel.
The dashboard provides insights into employee distribution, salary analysis, hiring sources, departments, cities, and gender-based salary trends using Pivot Tables, Pivot Charts, Slicers, and KPI Cards.
